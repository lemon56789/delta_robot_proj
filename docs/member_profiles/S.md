# S Profile

## Role
팀장, 하드웨어 제작/조립, 실험 진행 지원 담당. 동역학 해석과 진동 분석은 기획 단계 담당 범위로 유지한다.

## AI Prompt Seed
S는 팀장 및 하드웨어 제작 관점에서 답변을 원한다. 일정, 역할 분담, 조립/실험 진행 상태를 먼저 정리하고, 필요 시 기획 단계 동역학/진동 분석 관점도 함께 연결하라.

## Background
- 학부생 연구 프로그램에서 구형 로봇 주제를 수행했다.
- 해당 연구에서 동역학 해석 도구 RecurDyn과 MATLAB, Simulink를 사용해 본 경험이 있다.
- 진동동역학실습에서 Arduino, Autodesk, 3D 프린팅을 활용한 제작 경험이 있다.
- 제어 설계 관련 경험이 있어 로봇이나 강체 기반 실물 제작 주제에 선호가 있다.

## Scope
- 팀장 역할로서 일정, 역할 분담, 실험 진행 상황 정리
- 델타 로봇 하드웨어 제작, 조립, 실험 준비 지원
- 하드웨어 제작 상태와 제어/데이터 수집 단계 사이의 연결 확인
- 기획 단계에서 델타 로봇의 동역학 거동, 진동 특성, 오차 원인 해석 범위 검토
- 시간 제약상 심화 동역학 해석과 진동 분석은 실제 주 산출물보다 기획 및 해석 후보 범위로 둔다.

## Strengths
- 팀장 역할을 통한 진행 상황 조율 및 실험 준비 지원
- 하드웨어 제작과 조립 과정의 실제 참여
- 동역학 해석 및 진동 분석 경험
- 제어 설계 관점과 실물 제작 관점을 함께 연결할 수 있음
- 로봇 시스템의 거동을 시뮬레이션과 제작 관점에서 함께 볼 수 있음

## Weaknesses Or Cautions
- 제공된 기록 기준으로 데이터 기반 인공지능 모델링 경험은 핵심 강점으로 보이지 않는다.
- 답변 시 제어 및 동역학 중심 설명이 유효하지만, 학습 모델 상세 설계는 별도 검토가 필요할 수 있다.

- 하드웨어 제작/조립 체크리스트 정리
- 실험 진행 순서와 담당자 역할 정리
- 동역학 모델링 절차 정리
- 진동 원인 가설 정리 및 비교
- 실험 결과 해석 프레임 정리
- 시뮬레이션 조건 비교 기준 작성
- 실물 제작과 해석 결과를 연결하는 설명 정리

## Response Priorities
1. 팀장 관점에서 일정, 역할, 현재 진행 상태를 먼저 정리한다.
2. 하드웨어 제작/조립 상태와 실험 준비 상태를 분명히 한다.
3. 필요한 경우 진동과 동역학 관점의 원인/영향 경로를 기획 단계 해석으로 연결한다.
4. 실험 조건, 파라미터, 비교 기준과 기록 항목을 포함한다.
