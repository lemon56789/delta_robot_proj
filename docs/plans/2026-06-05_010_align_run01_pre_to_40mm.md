# Plan

## Goal
Arduino 쪽 Run 01-pre cross/square 이동 경로가 `40 mm` 기준이라는 점에 맞춰 main logger와 문서를 정리한다.

## Files
- `docs/plans/2026-06-05_010_align_run01_pre_to_40mm.md`
- `experiments/run01_main_logger.py`
- `experiments/run01_main_logger_computer2_powershell.md`
- `docs/hardware_experiment_run_01_baseline_data_collection.md`
- `docs/daily_notes/2026-06-05.md`

## Changes
- Run 01-pre 공식 cross/square trajectory를 `cross_pm40_pre`, `square_pm40_pre`로 바꾼다.
- `experiments/run01_main_logger.py`에 `cross_pm40_pre`, `square_pm40_pre`를 추가한다.
- 기존 `cross_pm10_pre`, `square_pm10_pre`는 호환용으로 남긴다.
- 컴퓨터 2 PowerShell 안내의 run_id와 출력 파일명을 `pm40` 기준으로 갱신한다.
- Run 01 문서의 pre trajectory table과 target range threshold를 `±40 mm` 기준으로 갱신한다.

## Impact
- Run 01-pre main log의 `target_x/y`가 실제 Arduino 이동 경로와 맞는다.
- CSV final contract, Arduino firmware, vision raw log contract는 변경하지 않는다.

## Risk
- vision logger 쪽 mode 이름이 아직 `cross_pm10_pre`만 지원하면, vision 파일명/run_id와 phase만 `pm40` 기준으로 맞추는 별도 조정이 필요할 수 있다.
- `±40 mm`는 `±10 mm`보다 이동 범위가 크므로 실제 하드웨어 간섭은 operator가 계속 관찰해야 한다.

## Validation
- `cross_pm40_pre`, `square_pm40_pre` dry-run으로 CSV 생성과 timestamp 단조 증가를 확인한다.
- 계산된 theta가 provisional range `-45..90 deg` 안에 있는지 확인한다.
- `git diff --check`로 문서/코드 공백 오류를 확인한다.
