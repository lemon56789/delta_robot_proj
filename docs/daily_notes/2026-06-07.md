## Entry 003
- 무엇을: Run 02에서 correction ON의 전체 `tracking_xy_rmse`가 악화된
  원인을 추가 진단하고 현재 확인된 문제점과 해석 제한을 기록했다.
- 왜: 기존 comparison 결과만으로 가상센서 모델 자체가 실패했다고
  결론내리기 전에 correction sign, 실제 actuator command 반영 여부,
  run 간 반복 정밀도와 circle 시간 정렬 영향을 분리해야 하기 때문이다.
- 어떻게: ON correction log의 predicted/applied correction과 OFF/ON
  vision tracking error 방향을 비교했다. Arduino firmware의
  `thetaToServoAngle()`과 serial RX의 integer `servo cmd`를 확인했다.
  각 OFF/ON pair의 초기 home vision 평균 위치를 비교하고, circle
  원운동 구간에 추가 time shift를 적용해 RMSE 민감도를 계산했다.
- 결과:
  - 모델 predicted error 방향은 OFF 실제 tracking error와
    `95.6~100%` 같은 방향이었다. correction은 그 반대 방향으로
    적용되므로 correction sign 자체는 정상으로 판단했다.
  - Arduino는 fractional theta를 수신하지만 최종적으로
    `servo.write()`에 전달하기 전에 integer servo angle로 반올림한다.
    ON command event 중 nominal OFF와 실제 integer servo command가
    달라진 비율은 cross `11.1%`, reverse grid `45.5%`, diamond
    `27.1%`, circle `33.0%`였다. 특히 cross에서는 보정 명령 대부분이
    실제 actuator command 변화로 이어지지 않았다.
  - correction이 없는 동일 home servo command에서도 OFF/ON 초기
    vision 위치 차이가 발생했다. pair별 최대 home shift는 cross
    `4.34 mm`, reverse grid `2.80 mm`, diamond `4.39 mm`, circle
    `1.85 mm`였다. 현재 correction 크기보다 백래시, zero drift 또는
    기구 반복 정밀도 영향이 클 수 있다.
  - 기존 circle 단일 departure alignment에서는 ON
    `tracking_xy_rmse`가 `25.41%` 악화됐다. 원운동 구간만 별도로
    shift sweep한 결과 OFF best RMSE는 `4.85 mm`, ON best RMSE는
    `4.22 mm`였고 ON에는 약 `350 ms` 추가 phase shift가 필요했다.
    이 조건에서는 ON이 약 `12.9%` 개선되므로 기존 circle 공식 결과는
    동적 위상 정렬에 민감하다.
  - Circle ON correction은 원운동 기준 평균 tangential correction
    약 `0.341 mm`를 포함했고, 측정 tangential error 평균은 OFF
    `0.048 mm`에서 ON `3.037 mm`로 증가했다. 모델이 정적 위치 오차와
    동적 lag를 구분하지 못하는 가능성이 있다.
  - 초기 home offset을 각 run에서 제거해 비교하면 diamond는 세
    repetition 모두 `10.61~20.55%` 개선됐지만 cross는 두 repetition이
    악화됐고 reverse grid는 `-5.96~+2.57%` 범위로 개선 근거가
    약해졌다.
  - 따라서 현재 결과를 모델 전체 실패 또는 전체 개선으로 확정하지
    않는다. Diamond 개선은 상대적으로 일관되지만 cross는 actuator
    resolution과 반복 정밀도, reverse grid는 baseline drift, circle은
    phase alignment와 동적 특성의 영향을 우선 해결해야 한다.
- 변경 파일: `docs/plans/2026-06-07_003_record_run02_diagnostic_findings.md`,
  `docs/daily_notes/2026-06-07.md`
- 다음: circle angular/phase alignment를 정식 구현하고, 실제 integer
